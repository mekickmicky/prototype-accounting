# WIND Accounting — Build Progress

Master progress tracker. Update when a phase reaches **all tasks `[x]`**.

## Conventions

- **Source of truth:** Each phase file in `specs/tasks/phase-*.md` holds the full task list with detailed `Done when` criteria.
- **This file:** A single-page summary so anyone can see overall build state in 5 seconds. Don't put detail here.
- **Language:** All code/files generated by tasks must be written in English. Thai allowed only in UI strings, PDF templates for Thai tax forms/invoices/WHT certs, `name_th` seeded columns, and i18n message catalogs. Same rule applies to commit messages.
- **Status legend:**
  - `⬜ Not started` — no task in this phase has been picked up
  - `🟡 In progress` — at least one task `[~]` or `[x]` but not all `[x]`
  - `✅ Done` — every task in the phase file is `[x]` AND the spec-11 acceptance criteria for that phase have been verified end-to-end

## Daily Loop (orchestrator-driven)

Use the orchestrator script `scripts/orchestrate.ts`. The main Claude session proposes; the user picks; child Claudes run in tmux panes.

### One-time setup
```bash
brew install tmux               # required for spawning child sessions
bun install                     # if not already
bun scripts/orchestrate.ts schedule    # generates SCHEDULE.md (21 waves)
```

### Each cycle (semi-auto)
```bash
# 1. See what's ready
bun scripts/orchestrate.ts ready

# 2. User picks 1–3 task IDs from the list (cap = MAX_PARALLEL=3)

# 3. Spawn (script auto-flips status [ ] → [~], creates tmux windows)
bun scripts/orchestrate.ts spawn T-1.1            # one task
bun scripts/orchestrate.ts spawn T-1.2 T-1.3 T-1.5    # up to 3 in parallel
bun scripts/orchestrate.ts spawn T-1.1 --dry-run  # preview the launch command

# 4. Watch the swarm
tmux attach -t wind-acc
#   Ctrl-b n / Ctrl-b p   switch panes
#   Ctrl-b d              detach (panes keep running)

# 5. When children finish, they self-mark [x]. Loop back to (1).

# Other useful subcommands
bun scripts/orchestrate.ts status     # what's wip / blocked / pane names
bun scripts/orchestrate.ts done T-X.Y # manual override (rare)
bun scripts/orchestrate.ts attach     # print attach command
```

### Provider routing (automatic in spawn)
| Task `Model` | Spawn runs |
|---|---|
| `Opus`     | `ai-anthropic && claude --model opus --permission-mode acceptEdits ...` |
| `Sonnet`   | `ai-anthropic && claude --model sonnet --permission-mode acceptEdits ...` |
| `DeepSeek` | `ai-deepseek && claude --permission-mode acceptEdits ...` (model set by alias) |

Aliases must exist in `~/.zshrc` (already configured).

### Phase rollover
When every task in a phase is `[x]`, run the phase's "Acceptance Criteria → Sub-task Mapping" smoke test end-to-end, then update this file's status emoji from `⬜` / `🟡` to `✅`.
